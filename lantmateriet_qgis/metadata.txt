name=Lantmäteriet Services
about=Connects QGIS to Lantmäteriet's (the Swedish land survey) APIs: search addresses, properties, joint facilities and common property units from the locator bar; download addresses, properties and common properties with Processing algorithms; add STAC and OGC service connections to the Browser; use property and address data in expressions. Requires a free account and an application in Lantmäteriet's API Manager (Consumer Key and Consumer Secret, configured in the plugin settings as an OAuth2 authentication). Covers Sweden only. The user interface is in Swedish; an English guide to all dialogs and algorithms is in the README.
